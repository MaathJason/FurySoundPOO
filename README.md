# FurySoundPOO

Projeto desenvolvido durante o curso **C# aplicando a Orientação a Objetos** da Alura.

## Descrição

Este projeto simula um sistema de gerenciamento de bandas, álbuns, músicas e podcasts, utilizando conceitos de Programação Orientada a Objetos (POO) em C#. O objetivo é praticar encapsulamento, composição, propriedades, listas e métodos, aplicando boas práticas de orientação a objetos.

## Funcionalidades

- **Bandas e Álbuns**
  - Cadastro de bandas.
  - Cadastro de álbuns para cada banda.
  - Adição de músicas aos álbuns.
  - Exibição de informações detalhadas das músicas, álbuns e discografia das bandas.

- **Podcasts**
  - Criação de podcasts com nome e host.
  - Adição de episódios a um podcast, com título, duração e número sequencial.
  - Inclusão de convidados em cada episódio.
  - Exibição detalhada dos episódios de um podcast, incluindo resumo e lista de convidados.

## Tecnologias Utilizadas

- C# 12.0
- .NET 8

## Estrutura Principal

- **Banda**: Gerencia álbuns e discografia.
- **Album**: Contém músicas e exibe informações do álbum.
- **Musica**: Representa uma música, com título, duração e disponibilidade.
- **Podcast**: Gerencia episódios e informações do podcast.
- **Episodio**: Representa cada episódio, com título, duração, número e convidados.

## Como Executar

1. Clone o repositório.
2. Abra o projeto no Visual Studio 2022.
3. Compile e execute a aplicação.

## Aprendizados

- Criação e uso de classes e objetos em C#.
- Encapsulamento de dados com propriedades.
- Composição de objetos e relacionamento entre classes.
- Manipulação de listas e métodos.
- Aplicação de boas práticas de POO.
